# Bug fix

Reproduce the failure before editing. Read the current file version, prefer a
small version-checked mutation, and run the user's authoritative validator soon
after the first meaningful change. Treat validator evidence as authoritative.

Load `references/checklist.md` only when a detailed repair checklist is needed.
