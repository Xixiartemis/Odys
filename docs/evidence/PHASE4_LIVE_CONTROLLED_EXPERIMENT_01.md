# Phase 4 live controlled experiment

Status: `NOT_RUN_IN_CODEX_ENVIRONMENT`

This evidence bundle is generated by
`scripts/phase4_live_controlled_experiment.py` after a human-side real-provider
execution. Codex does not invoke the provider or inspect credentials.

The run freezes the committed Phase 4 snapshot, the CWR-06 fixture, and the
`FAIL_TOOL_ON_CALL_1` fault for the paired baseline/V2 arms. The clean control
arm uses the same frozen task and fixture with an execution-local no-fault
adapter; no frozen input file is rewritten.

## Arms

| Arm | Harness | Config | Fault | Repeats |
|---|---|---|---|---:|
| `clean_control` | `RECOVERY_CONTROL_PLANE_V2` | `odys_p3` | `NONE` | 3 |
| `baseline_fault` | `BASELINE` | `minimal` | `FAIL_TOOL_ON_CALL_1` | 3 |
| `v2_fault` | `RECOVERY_CONTROL_PLANE_V2` | `odys_p3` | `FAIL_TOOL_ON_CALL_1` | 3 |

The script uses `Phase4Runner`, `P45BenchmarkExecutor`, the real P46 provider
adapter, and the existing real minimal/Odys runtime factories. It constructs
the SDK client with `max_retries=0`, records secret-free provider identity, and
keeps raw, invalid, trace, workspace-audit, and aggregation artifacts isolated
per arm.

Run on the credential-bearing machine:

```powershell
Set-Location -LiteralPath 'D:\projects\odys-p411-official'
$env:PYTHONPATH = 'D:\projects\odys-p411-official'
& 'D:\projects\odys\.venv\Scripts\python.exe' -B `
  'D:\projects\odys-p411-official\scripts\phase4_live_controlled_experiment.py' `
  --repo-root 'D:\projects\odys-p411-official' `
  --output 'D:\projects\odys-p411-official\results\phase4_live_controlled_experiment_01'
```

To regenerate only derived evidence from an existing bundle, without provider
access and without rewriting `raw.jsonl`, `traces.jsonl`, or `invalid.jsonl`:

```powershell
& 'D:\projects\odys\.venv\Scripts\python.exe' -B `
  'D:\projects\odys-p411-official\scripts\phase4_live_controlled_experiment.py' `
  --repo-root 'D:\projects\odys-p411-official' `
  --output 'D:\projects\odys-p411-official\results\phase4_live_controlled_experiment_01' `
  --reaggregate
```

The derived report classifies this CWR-06 bundle as
`LOCAL_RECOVERY_SMOKE`. It reports `COST_COMPARISON=NOT_COMPARABLE` when the
baseline and V2 outcomes differ, treats a no-fault arm as
`FAULT_INJECTION_SKIPPED`, and records missing historical
`FAULT_TRIGGERED` telemetry as `NOT_AVAILABLE_FOR_OLD_RUN`. A zero duplicate
mutation count is not promoted to proof, so its rate remains `NOT_PROVEN`.

The generated report must use `NOT_MEASURED` for unavailable token/cost
telemetry and must not claim linear context-growth elimination from character
projection alone.
