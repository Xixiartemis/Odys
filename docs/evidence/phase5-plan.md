# Phase 5 Evidence Plan

The canonical Phase 5 design is [../../docs/phase5-benchmark-plan.md](../phase5-benchmark-plan.md).

Phase 5 must preserve pair identity, distinguish valid task outcomes from
invalid infrastructure runs, and report cost only for validator-equivalent
outcomes. The minimum resume-grade target is 30 independent task-condition
pairs; the preferred target is 50–100 valid pairs across at least 10 tasks
and three or more meaningful failure conditions.

The first public-facing claim must remain scoped to the measured task set,
model, provider, validator, and frozen harness. A second model family is a
later generalization check and is not required before the first evidence
package.
