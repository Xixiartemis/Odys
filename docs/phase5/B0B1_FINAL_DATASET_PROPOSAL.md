3. 抽样算法（固定 seed，可复算）
═══════════════════════════════════════════════════════════

- seed = **42**（与 pilot 冻结 selection_seed 一致）。
- 算法（`scripts/phase5_route_experiment_manifest.py::sample_pairs`）：
  1. 池按 unit_id 排序；
  2. 16 格（C1–C4 × P1–P4）遍历，每格 `random.Random(42).choice`
     抽 min(per_cell, 可用) 个，逐格记录选择与池大小（cell_audit）；
  3. 已用基础任务全局去重（一 base 一变体）；
  4. 不足部分按 `rng.shuffle(格序)` 后补抽至总数；
  5. 结果按 unit_id 排序输出。
- per_cell = total // 16：30→1(+14 补抽)、50→3(+2 补抽)、100→6(+4 补抽)。
- 确定性：同 seed 同池 → 同清单（cell_audit 逐格可核）。
